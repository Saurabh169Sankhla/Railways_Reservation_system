## **Railway Reservation System**

This is a mini DBMS project simulating a basic railway reservation system. It includes features like booking management, database schema, and simple user interactions.

## **What's Included**

-Database schema (SQL file)
-Basic logic for booking, cancellation, and search
-Frontend interface
-Backend logic

## **Technologies**

-SQL
-Python
-HTML/CSS

## **How to use**

-Import the provided .sql file into a DBMS like MySQL.
-Open the web interface or use terminal-based options
-Run the program and interact with the system.
